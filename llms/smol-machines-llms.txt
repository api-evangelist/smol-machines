# smol machines

> The same smol machine on your laptop, in the cloud, or self-hosted. smolmachines runs fast, isolated microVMs — "machines" — from any OCI image: locally with the open-source `smol` CLI, or on the smolmachines cloud platform. This file indexes the site for automated agents.

## Product

- [Home](https://smolmachines.com): The same smol machine on your laptop, in the cloud, or self-hosted.
- [Browse machines](https://smolmachines.com/machines): Catalog of ready-to-run base machines.
- [Pricing](https://smolmachines.com/pricing): Usage-based pricing across the Standard, Startup, and Enterprise tiers.
- [Registry](https://smolmachines.com/registry): Public registry of .smolmachine artifacts.
- [Documentation](https://smolmachines.com/docs): Full documentation home.
- [Engineering](https://smolmachines.com/engineering): Engineering notes on the runtime under smol machines.
- [Running a real Kubernetes cluster inside one microVM](https://smolmachines.com/engineering/kubernetes-in-a-microvm): Why a microVM can host nested Kubernetes where a container cannot.
- [GPU access by API remoting](https://smolmachines.com/engineering/gpu-over-vsock): Remoting the CUDA API over vsock to a host GPU, and how it compares to passthrough and vGPU.
